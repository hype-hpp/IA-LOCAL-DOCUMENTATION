# IA Local — Hardware

## Sistema principal

| Componente | Especificação |
|---|---|
| CPU | Ryzen 7 5800X3D |
| GPU | RTX 4070 Ti SUPER |
| VRAM | 16 GB |
| RAM | 32 GB DDR4 |
| SSD | Samsung 990 PRO |
| Espaço livre | ~404 GB |
| Sistema operacional | Arch Linux |

## Observações

- Modelos que excedem 16 GB de VRAM podem exigir offload para RAM.
- Offload deve ser medido empiricamente; não assumir desempenho a partir do número de parâmetros.
- Armazenamento é um recurso importante: o sistema deve possuir limites, deduplicação, retenção e cache controlados.
- O comportamento de cada modelo deve ser avaliado no hardware real.
